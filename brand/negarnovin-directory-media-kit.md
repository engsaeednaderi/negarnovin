## Short description
NegarNovin is an Iran-based hosting and infrastructure services provider established in 2009. Its services include KVM-based virtual private servers, cloud and dedicated server services, web hosting, SSL certificates, domains, server administration and infrastructure support. VPS resources, supported operating systems, locations and current prices are published in the official service catalogue.

## Long description
NegarNovin provides virtual server and hosting services for businesses, developers and individual customers. Its catalogue includes KVM virtual servers with plan-specific CPU, RAM and NVMe storage configurations, as well as services for web hosting, SSL certificates, domains and managed server administration. Customers can review available locations and supported operating systems through the official catalogue and order portal. Infrastructure may be supplied through third-party data-center and infrastructure partners; NegarNovin should not be described as owning every facility in which a service is hosted.
