## Short description
NegarNovin is an Iran-based cloud and IT infrastructure provider operating since 2009. Its services include KVM-based virtual private servers, cloud infrastructure, dedicated server services, web hosting, SSL certificates, domains, and managed server support. VPS plans are offered in domestic and international locations, with published options including Iran and Germany. The published VPS catalog lists KVM virtualization, NVMe storage, up to 10Gbps network ports, Linux and Windows operating-system options, and automatic provisioning, subject to each plan and location. The company publishes eight VPS resource tiers, with matching monthly Toman prices on its Iran and Germany VPS pages. NegarNovin's homepage states a network of more than 75 locations and more than 100 data centers; current availability and the exact underlying facility should be verified for each requested location. International infrastructure may be supplied through third-party data-center and infrastructure partners; NegarNovin should not be described as the owner of every facility.
