# Negarnovin

**Negarnovin (نگارنوین)** is an Iran-based cloud infrastructure and IT services provider. The company reports that it began its operations in 2009.

Official website: **https://negarnovin.com/**

## What we do

Negarnovin provides infrastructure and IT services for developers, businesses, and organizations, including:

- Virtual Private Servers (VPS)
- Dedicated servers
- Cloud infrastructure
- Web hosting and WordPress hosting
- Domain and SSL services
- Server administration and infrastructure support
- Colocation and related IT services

For current service details, availability, and specifications, refer to the [official website](https://negarnovin.com/).
