# Negarnovin

**Negarnovin (نگارنوین)** is an Iran-based cloud infrastructure and IT services provider. The company reports that it began its operations in 2009 (1388 in the Iranian calendar).

Official website: **https://negarnovin.com/**

## Services

- Virtual Private Servers (VPS)
- Dedicated servers
- Cloud infrastructure
- Web hosting and WordPress hosting
- Domain and SSL services
- Server administration and infrastructure support
- Colocation and related IT services

Current plans, availability, technical specifications, and service terms are published on the [official website](https://negarnovin.com/).
