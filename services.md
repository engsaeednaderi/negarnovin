# Negarnovin — Services

Negarnovin publishes infrastructure and IT services for developers, businesses, and organizations. This page summarizes service categories; current plans, prices, availability, and technical specifications should always be checked on the relevant product page.

## Virtual servers (VPS)

Virtual Private Server services provide virtualized compute environments for websites, applications, development, testing, and server workloads.

Official service page: https://negarnovin.com/vps/

When evaluating a VPS, compare the allocated vCPU, RAM, storage type and capacity, network policy, location, operating-system options, backup policy, support scope, and renewal price.

## Dedicated servers

Dedicated server solutions are intended for workloads that require physical server resources or more direct control over the host environment.

Before ordering, confirm the exact CPU model, memory, disks, RAID options, port speed, traffic policy, remote management, IP allocation, and replacement/support terms.

## Cloud infrastructure and hosting

Negarnovin also lists cloud infrastructure, web hosting, and WordPress hosting among its service areas. The appropriate product depends on the workload, performance requirements, administration needs, and expected traffic.

## Domains and SSL

Domain and SSL services support domain naming and encrypted connections for websites and applications. Product availability and supported certificate types may change, so consult the current store.

SSL store: https://negarnovin.com/index.php?rp=/store/ssl

## Server administration and IT support

Infrastructure support can include server setup, operating-system configuration, troubleshooting, and related IT operations. The precise scope should be agreed for each service.

## Colocation

Colocation is a service category for customers who need to place physical hardware in a data-center facility. Facility, power, connectivity, remote hands, and contract details should be confirmed before purchase.

## Choosing an infrastructure service

A useful selection process is:

1. Describe the workload and expected traffic.
2. Estimate CPU, memory, storage, and network requirements.
3. Choose a data-center location based on latency, legal requirements, and audience.
4. Confirm backup, security, monitoring, and support responsibilities.
5. Compare the full recurring cost, not only the introductory price.

For current service information, use the [official Negarnovin website](https://negarnovin.com/).
